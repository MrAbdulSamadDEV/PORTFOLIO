# Abdul Samad Portfolio CLI

## Run

```bash
npx abdulsamad
```

## Commands

```bash
npx abdulsamad
npx abdulsamad --help
npx abdulsamad --version
```

## Requirements

Node.js 18+

## Platform

Windows
macOS
Linux

## Portfolio

https://abdulsamad-pro.vercel.app

This package is a lightweight terminal launcher for the portfolio. It opens the portfolio website in the default browser.
